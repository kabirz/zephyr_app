# 无线接收器用户使用手册

数据中转网关：接收手柄端通过 nRF24L01+ 发来的无线数据，通过 W5500 以太网 UDP 转发给上位机；同时把上位机下发的扫描仪数据透传给手柄。

---

## 1. 硬件与默认配置

| 项目 | 默认值 |
|------|--------|
| MCU | STM32F103RC @ 72 MHz |
| 以太网 | W5500 (SPI3) |
| 无线 | nRF24L01+ (SPI2), 1 Mbps, 0 dBm |
| 默认 IP（静态模式） | `192.168.11.220` |
| 子网掩码（静态模式） | `255.255.255.0`（固定，不可配） |
| 网关（静态模式） | IP 末段改为 1（如 `192.168.11.1`，运行时派生） |
| 默认网络模式 | 静态 IP（DHCP 关闭） |
| 数据端口 | `9600`（可配） |
| 配置端口 | `8601`（固定） |
| nRF24 信道 | `1`（可配） |
| nRF24 地址 | 5 字节，默认 `00 00 00 00 00`（可配） |

**指示灯（低电平亮）：**
- **PA1（2.4G 状态）**：nRF24 初始化后常亮；收发数据时闪烁
- **PA2（错误）**：硬件错误 / hardfault / nRF24 初始化失败时点亮，锁定不灭
- **PA3（系统）**：进入主循环后点亮，标志系统就绪

---

## 2. 端口说明

| 端口 | 协议 | 用途 | 是否可配 |
|------|------|------|----------|
| **8601** | UDP | 配置命令（0x12–0x17）+ 固件升级（0x01–0x05） | 固定 |
| 8602 | UDP | 配置回复的广播目标（跨子网时） | 固定（8601+1） |
| **9600** | UDP | 数据收发：nRF24↔上位机透传 | 可配（SET_NET） |
| 9601 | UDP | 数据广播目标（跨子网/未学习源时） | 跟随数据端口 |

> **上位机收发约定**：上位机监听 `数据端口+1`（默认 9601），向网关的 `数据端口`（默认 9600）发送。

## 3. 网络配置协议（UDP 端口 8601）

所有配置命令格式统一为 `[命令字节 1B][数据...]`，回复格式为 `[命令字节 1B][回复数据...]`。

多字节整数一律**大端序（Big-Endian，网络字节序）**。

### 3.1 SET_NET（0x12）—— 设置 IP 和数据端口

```
请求: [0x12][ip 4B BE][port 2B BE]      共 7 字节
回复: [0x12][ip 4B BE][port 2B BE]      共 7 字节
```

| 字段 | 说明 |
|------|------|
| ip | 静态模式下为要设置的 IP；**DHCP 模式下此字段被忽略**（IP 由 DHCP 分配） |
| port | 数据端口（1–65535） |

- **持久化**：是（重启保持）
- **生效时机**：IP 变更需**重启**生效；数据端口变更也建议重启（数据接收线程在启动时绑定端口）
- DHCP 模式下只改端口，IP 不受影响

### 3.2 GET_NET（0x13）—— 查询 IP 和数据端口

```
请求: [0x13]                             共 1 字节
回复: [0x13][ip 4B BE][port 2B BE]      共 7 字节
```

返回的 IP 取自**当前活动接口地址**：DHCP 模式下是 DHCP 实际分配的地址，静态模式下等于配置的 IP。

### 3.3 SET_RF24（0x14）—— 设置无线信道和地址

```
请求: [0x14][ch 1B][addr 5B]             共 7 字节
回复: [0x14][ch 1B][addr 5B]             共 7 字节
```

| 字段 | 说明 |
|------|------|
| ch | 信道（0–125）；超过 125 则信道保持不变，但地址仍更新 |
| addr | 5 字节地址，原样写入 `addr[0..4]` |

- **持久化**：是
- **生效时机**：**立即生效**（热更新无线电配置，无需重启）
- 开启加密时，地址变更会自动重新派生加密密钥

### 3.4 GET_RF24（0x15）—— 查询无线配置

```
请求: [0x15]                             共 1 字节
回复: [0x15][ch 1B][addr 5B]             共 7 字节
```

### 3.5 SET_NET_MODE（0x16）—— 设置网络模式（静态/DHCP）

```
请求: [0x16][mode 1B]                    共 2 字节
回复: [0x16][mode 1B]                    共 2 字节
```

| mode 值 | 含义 |
|---------|------|
| 0x00 | 静态 IP |
| 0x01 | DHCP |

- **持久化**：是
- **生效时机**：**需重启**（DHCP 客户端只在启动时根据此配置启动）

### 3.6 GET_NET_MODE（0x17）—— 查询网络模式

```
请求: [0x17]                             共 1 字节
回复: [0x17][mode 1B]                    共 2 字节
```

## 4. 数据收发协议（UDP 端口 9600）

数据端口传输的帧格式与 nRF24 空口帧一致（**明文，未经网关修改**）：

```
[帧ID 2B BE][载荷 0–30B]
```

### 4.1 无线接收器 → 上位机（上行，手柄的数据）

无线接收器只转发以下两类帧到上位机：

| 帧ID | 名称 | 含义 |
|------|------|------|
| `0x1E3` | HANDLER_STATE | 摇杆状态（角度 + 按键） |
| `0x763` | COBID_HEATBEAT | 心跳（1 字节载荷 `0x05`） |

**HANDLER_STATE（0x1E3）载荷格式：**

```
[x_angle 2B BE][y_angle 2B BE][button 1B][0xFF][0xFF][0xFF]   共 8 字节
```

| 字段 | 类型 | 单位/范围 | 说明 |
|------|------|-----------|------|
| x_angle | int16 BE | 0.1°（-200~+200 表示 -20.0°~+20.0°） | 摇杆 X 轴角度 |
| y_angle | int16 BE | 0.1°（同上） | 摇杆 Y 轴角度 |
| button | uint8 | 0/1 | handler 按键状态 |
| 后 3 字节 | — | 固定 0xFF | 填充 |

**上位机解析示例（x_angle 为有符号数）：**
```python
import struct
x_angle, y_angle, button = struct.unpack('>hhB', data[:5])
print(f"X={x_angle/10:.1f}°  Y={y_angle/10:.1f}°  btn={button}")
```

**心跳帧（0x763）**：载荷 1 字节，值固定为 `0x05`。周期约 800 ms。

### 4.2 上位机 → 无线接收器（下行，控制扫描仪）

上位机发到无线接收器数据端口的帧，无线接收器只透传以下三类到 nRF24：

| 帧ID | 名称 | 含义 |
|------|------|------|
| `0x263` | OVERBREAK_LASER | 超欠挖 + 激光测距 |
| `0x363` | COORD_XY | X/Y 坐标 |
| `0x463` | COORD_Z | Z 坐标 |

载荷格式详见手柄文档（与扫描仪数据协议一致）。

**上位机发送示例（Python）：**
```python
import socket, struct
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
# 发送 OVERBREAK_LASER 帧: overbreak=123mm(有符号), laser=4567mm
frame_id = 0x263
data = struct.pack('>H', frame_id)           # 帧ID 大端
data += bytes([0x03, 0x00])                  # flags: bit0=OB有效, bit1=laser有效
data += struct.pack('>h', 123)               # overbreak int16 BE
data += struct.pack('>i', 4567)              # laser int32 BE
sock.sendto(data, ('192.168.11.220', 9600))
```

### 4.3 上行 UDP 路由规则

无线接收器发送上行数据时：
- 若上位机曾发过下行帧且与无线接收器**同子网** → **单播**到上位机源地址
- 否则（跨子网 / 从未学习）→ **广播**到 `255.255.255.255:数据端口+1`

> 建议：上位机先发一帧下行帧让无线接收器学习地址，之后即可稳定单播接收。

### 4.4 链路断开行为

- 网线未插 / 链路 down 时，上行 nRF24 数据**静默丢弃**（不缓存）
- 无线接收器启动时等待链路 up 最多 5 秒，超时后继续启动；链路恢复后自动恢复转发

## 5. 固件升级协议（UDP 端口 8601）

| 命令 | 流程 |
|------|------|
| `0x01` FW_START | 请求 `[0x01][size 4B LE]` → 回复 `[0x01][status]`（1=成功，擦除 slot1） |
| `0x02` FW_DATA | 请求 `[0x02][数据 ≤511B]` → 回复 `[0x02][已写入偏移 4B LE]` |
| `0x03` FW_END | 请求 `[0x03][test 1B][crc 2B LE]` → 回复 `[0x03][result]`；CRC 校验通过后重启升级 |
| `0x04` GET_VERSION | 请求 `[0x04]` → 回复 `[0x04][版本字符串]`（如 `0.1.0-dev`） |
| `0x05` REBOOT | 请求 `[0x05]` → 回复 `[0x05]` 后 100ms 冷重启 |

- CRC 算法：CRC16-CCITT，校验 slot1 回读数据
- 升级流程：FW_START → 多次 FW_DATA → FW_END（校验通过自动重启进入新固件）

## 6. Shell 命令（串口终端）

连接串口（波特率见板级配置），可使用以下命令：

### `gw` —— 网络相关

| 命令 | 说明 |
|------|------|
| `gw info` | 显示当前 IP、掩码、网关、数据端口、配置端口、运行状态 |
| `gw send <id_hex> <b0> [b1 ...]` | 发送原始 UDP 帧（如 `gw send 1e3 01 02 ff`） |
| `gw ping [count=5]` | 向上位机发 TEST_FRAME ping |
| `gw ip [addr]` | 查看/设置静态 IP（DHCP 模式下拒绝）；需重启生效 |
| `gw port [1-65535]` | 查看/设置数据端口；需重启生效 |

### `rf24` —— 无线相关

| 命令 | 说明 |
|------|------|
| `rf24 info` | 显示 nRF24 状态、信道、地址 |
| `rf24 ch [0-125]` | 查看/设置信道（立即生效，**不持久化**） |
| `rf24 addr <b0 b1 b2 b3 b4>` | 设置 5 字节地址（立即生效，**持久化**） |
| `rf24 send <text...>` | 发送 DATA 测试帧 |
| `rf24 ping [count=5] [interval_ms=200]` | nRF24 链路 ping 测试（往返延迟） |
| `rf24 listen [on\|off]` | 监听模式开关（打印收到的 DATA，自动应答 PING） |
| `rf24 diag` | 打印 nRF24 寄存器快照 |

## 7. 配置持久化

配置存储在 Flash（FCB 后端），重启后保持：

| 存储键 | 内容 |
|--------|------|
| `gw/rf24_channel` | nRF24 信道 |
| `gw/rf24_addr` | nRF24 5 字节地址 |
| `gw/ip_addr` | 静态 IP 地址 |
| `gw/data_port` | 数据端口 |
| `gw/use_dhcp` | 网络模式（0=静态，1=DHCP） |

---

## 8. 加密（可选功能）

通过编译开关 `CONFIG_NRF24L01P_CRYPT` 控制（需在网关和手柄**两端同时**开启或关闭）：

- **开启时**：nRF24 空口数据用 XXTEA-CTR 加密，密钥由 5 字节无线地址派生
- **对上位机 UDP 协议无影响**：无线接收器解密后再以明文 `[帧ID][载荷]` 转发给上位机，上位机无需感知加密
- 默认关闭

## 9. 典型使用流程

### 场景一：配置无线接收器网络

```
1. 上位机发送 (UDP 8601):
   0x12 C0 A8 0B DC 25 80        → 设置 IP=192.168.11.220 端口=9600
2. 上位机发送:
   0x16 00                        → 静态 IP 模式
3. 无线接收器重启生效
```

### 场景二：配置无线参数

```
1. 上位机发送 (UDP 8601):
   0x14 01 E7 E7 E7 E7 E7         → 信道=1(0x01) 地址=E7 E7 E7 E7 E7
2. 立即生效，无需重启
3. 手柄端也需配置相同的信道和地址
```

### 场景三：接收摇杆数据

```
上位机监听 UDP 9601:
- 收到 [07 77 ...]: 测试帧（忽略或处理）
- 收到 [01 E3 xx xx yy yy btn FF FF FF]: 摇杆状态
- 收到 [07 63 05]: 心跳
```
